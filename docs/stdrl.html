Holdings — what to buy and hold

A rules-based book. Every line states the signal that put it in and the rule that would take it out. Deterministic: no model, no randomness, same inputs give the same book.

Exits and replacements

An exit needs only ONE trigger; an entry needs every gate to pass. A name that exits is barred from re-entry for a cool-off, so a stop cannot be undone by the next pass buying it straight back.

Agent comparison

Deep reinforcement-learning agents trained on a basket of NSE/BSE names and ranked on risk-adjusted return. Training runs offline; this page shows the baked result.

Performance

Ranked by Sharpe, then CAGR. An agent whose Sharpe could not be computed sorts last rather than counting as zero — unknown is not neutral.

Equity curves

Net worth per agent over the evaluation window, from a common starting balance.

Rules-based research tool for education only — not personalized investment advice, and emphatically not a trading system. Back-tested agent performance on historical bars says nothing reliable about future returns.
